# A股决策台

一个不连接券商、不自动下单的日线选股与持仓管理工具。

## 已实现

- BaoStock 沪深300成分股、指数日线、行业和结构化财务数字增量缓存。
- SQLite 保存行情、估值、财务快照、成分股历史、因子、风险、持仓和任务日志。
- 趋势、动量、量价、波动、估值和财务质量的多因子综合筛选。
- 五万元账户的风险仓位和最多三只持仓约束。
- 持仓止损、MA20退出、2R减仓和大盘风险退出。
- 独立风险模型和每日风险倒排，不用机会排名的反数代替风险。
- 可选本地 Kronos 辅助评分；可解释的数字因子占 90%。
- Web 仪表盘、买卖录入、行情更新、推荐触发和风险提示。

## 当前推荐算法

以下内容对应 `stockapp/strategy.py` 和 `stockapp/kronos_service.py` 的当前实现。
策略只使用结构化数字，不读取舆情或财报文本。

### 1. 数据和股票池

- 当前有效的沪深300成分股，每只最多读取 600 根日 K，少于 250 根跳过。
- 日频字段：OHLC、成交量、成交额、换手率、PE TTM、PB MRQ、PS TTM、PCF TTM。
- 财务数字：盈利、成长、运营、偿债、现金流和杜邦数值；只使用 `publish_date <= 决策日` 的快照。
- 估值指标使用行业内百分位；行业样本少于 4 只时退回全市场百分位。
- 停牌、ST、数据日期与指数不一致或必需指标不完整的股票跳过。

### 2. 指标层

除 MA20/60/120、ATR14和相对强弱外，当前还计算：

```text
EMA12 / EMA26 / MACD / MACD signal / MACD histogram
RSI14 / KDJ(9) / ROC20
OBV及10日斜率 / MFI14 / 上涨下跌成交量比
5日与20日成交额比 / 20日成交量中位数
20日年化波动率 / 下行波动率 / 20日回撤
60日Beta / 与沪深300的60日相关性
ROE / 净利率 / 净利润同比 / 经营现金流净额比 / 负债率
```

MACD、KDJ、RSI 不是各自独立投票，而是被限制在趋势或动量因子组的固定权重中。

### 3. 市场环境分

市场环境从原来的二元开关改为 0–100 分，由以下数字构成：

- 沪深300收盘价与 MA20/60/120 的关系及 MA20/60 排列。
- 成分股位于 MA20、MA60 上方的比例。
- 20 日上涨股比例和 20 日新高比例。
- 指数 20 日波动率和近 5/20 日成交额比。

```text
市场分 >= 65  -> RISK_ON，允许开新仓
50 <= 市场分 < 65 -> CAUTIOUS，不开新仓
市场分 < 50 -> RISK_OFF，不开新仓
```

### 4. 机会分

每只股票生成 0–100 的 `opportunity_score`：

| 因子组 | 最终权重 | 主要内容 |
|---|---:|---|
| 趋势 | 20% | 均线位置与排列、MA20斜率、MACD方向与加速、20日突破 |
| 动量 | 15% | 20日相对强弱的横截面排名、RSI区间、KDJ时机 |
| 量价 | 20% | 成交量和成交额排名、OBV、MFI、上涨/下跌成交量比 |
| 波动质量 | 10% | 波动率横截面排名、ATR合理区间、Beta距离1的程度 |
| 估值 | 10% | 正 PE/PB/PS/PCF 的行业内百分位，负值不当作便宜 |
| 财务质量 | 15% | ROE、净利率、净利润增长、CFO/净利润、负债率 |
| Kronos | 10% | 未来5日预测收益 |

未启用 Kronos 时，前六个结构化因子按比例归一化为 100 分。
启用时，只对基础机会分前 `max(top_k × 2, 10)` 只推理，最终为
`base_score × 90% + kronos_score × 10%`。非有限模型结果或推理异常会退回纯因子分。

### 5. 独立风险分与倒排

`risk_score` 不是机会分的反数，而是单独计算：

| 风险组 | 基础权重 | 主要内容 |
|---|---:|---|
| 趋势破坏 | 25% | 跌破MA20、MA20低于MA60、MACD负值与负向加速 |
| 下行与尾部风险 | 20% | 下行波动率和20日回撤的横截面排名 |
| 量价派发 | 20% | OBV下行、下跌成交量占优、MFI偏弱 |
| 流动性衰减 | 15% | 近5日成交额相20日显著萎缩 |
| 财务风险 | 10% | 财务质量综合分的反向 |
| 估值风险 | 10% | 行业估值分的反向，包括负 PE/PCF |

启用 Kronos 后，基础风险分占 90%，模型下行收益换算的风险占 10%。
每日会为全股票池保存因子快照，并独立输出风险最高的 5 只；
`risk_score >= 65` 标为 `HIGH_RISK`，否则为 `CAUTION`。

### 6. 置信度

`confidence` 表示数据完整性，不代表上涨概率。OHLCVA 指标完整时基础为 60，
再根据换手率、四个估值字段、财务字段和 Kronos 成功输出递增。
缺失值获得中性因子分并降低置信度，不会被当成 0。

### 7. BUY 门槛和仓位

```text
市场状态 = RISK_ON
机会分 >= 72
风险分 <= 35
置信度 >= 70
20日平均成交额 >= 5亿元
5元 <= 收盘价 <= 100元
账户回撤 > -5%
持仓 < 3只，总仓位 < 60%
```

每日最多产生 1 个 `BUY`。止损与数量仍按以下公式，并向下取整到 100 股：

```text
止损距离 = min(2 × ATR14, 计划价 × 6%)
风险股数 = floor((账户权益 × 0.5%) / 止损距离 / 100) × 100
仓位股数 = floor((账户权益 × 20%) / 计划价 / 100) × 100
推荐股数 = min(风险股数, 仓位股数)
```

### 8. 持仓管理与输出

持仓动作优先级不变：触发当前止损、连续两日低于 MA20，或
`RISK_OFF` 且个股低于 MA20 时 `SELL`；达到 2R 后 `REDUCE` 一半，
剩余部分使用 `max(旧止损, 成本, 最高收盘 - 2×ATR14)` 移动止损。

页面同时展示：持仓 `HOLD/REDUCE/SELL`、机会榜前 5 名的 `BUY/WATCH`、
风险倒排前 5 名及其可解释原因。

## 启动

```bash
cd stock_assistant
conda activate stock
python -m pip install -r requirements.txt

# 首次同步会下载沪深300历史日线，之后只拉增量
python -m stockapp.cli sync

# 旧数据库首次升级：补齐历史换手率和估值字段，当前已经补齐所有数据，正常不需要再运行
python -m stockapp.cli backfill-bars

# 财务数字按报告期同步；新季报披露完成后再执行相应季度
python -m stockapp.cli sync-financials --year 2026 --quarter 1

# 可选：保存历史月度沪深300成分股快照，供后续严格回测使用
python -m stockapp.cli backfill-membership --start 2018-01-01 --end 2026-07-17

# 先跑规则版；加 --kronos 会对候选股调用本地模型
python -m stockapp.cli recommend
python -m stockapp.cli recommend --kronos

python run.py
```

本地打开 `http://127.0.0.1:5001`。Ubuntu 服务器如果需要外网访问，应在前面配置
Nginx HTTPS 和身份认证，不要直接将 Flask 端口公开。

## 数据缓存

数据默认保存在 `data/stocks.db`。每只股票同步前查询数据库的最新交易日：

```text
无缓存：2018-01-01 -> 今天
有缓存：最新交易日 + 1天 -> 今天
```

`daily_bars` 使用 `(code, trade_date)` 作为主键，重复同步不会产生重复行。
换手率和 PE/PB/PS/PCF 随日线保存；财务数字按发布日期保存到
`financial_snapshots`，行业和历史成分股分别保存到 `industry_history` 与
`index_membership_snapshots`。每次推荐的全市场因子及风险倒排会写入
`factor_snapshots` 和 `risk_alerts`，方便复盘当日决策。

## 定时运行

`deploy/` 包含 systemd 服务和定时器示例。根据 Ubuntu 上的实际用户、项目路径和
Conda 路径修改后安装。每日任务默认工作日 `08:10` 运行；BaoStock 日线实际上更新的
是上一个已收盘交易日。

## 当前边界

- 不会自动下单，页面中的买入是 `9:35-10:00` 的条件计划。
- 按设计不读取新闻、舆情、公告正文或财报文本，只使用行情、估值和已披露财务数字。
- 风险提示也是日频数字模型，无法识别停牌、监管调查、突发公告等事件风险。
- Kronos 微调数据截止 2026-07-03，此前历史区间不是它的独立测试集。
- 推荐是决策辅助，不保证收益或 10% 绝对回撤上限。
